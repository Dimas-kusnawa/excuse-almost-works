A program that writes one line to `/output/entry.txt` (103 characters, inside the 140-character gate; 16 words, inside the 20-word cap): the text a gamer sends the boss to skip work on GTA 6 launch week — builders cut the street's broadband cable, so he's offline till Friday, and the timing is, he insists, honestly awful. It never mentions the game, which is exactly why a tired manager would almost believe it.

## Run it

```sh
python3 main.py
```
